## Scope-proportionality gate

The three-review scope round did not authorize weakening the source contracts above. TI-D054 makes sole-source capture explicit: each manual only-X path captures only X, and each automatic only-X path captures only X plus exactly its declared controls. Under TI-D055/TI-D056, every valid source-qualified unit under current physical/authorization generations has a durable representation; control units remain bounded operational evidence and absent from product history unless independently product-eligible. The release-sized evidence model is shared model/property tests for cross-source invariants, one parameterized source-adapter contract, six manual production-query slices, one shared automatic-control contract exercised against six capture plans, exact v27→v28 migration/recovery execution, and a small representative physical-provider smoke. Broader OEM/Doze/multi-SIM/soak coverage is risk-based backlog rather than fabricated fleet evidence.

# Retained Steps recording lifetime

IMPLEMENTATION_ONLY / IMPLEMENTED_UNVALIDATED. Eight authored methods NOT_RUN.

Approved recording-origin foundation is now connected to the existing native
retained session selector. Authenticated marked facts may cross quality-only or
other-source manifests while retaining the original attribution. Real Steps
recording boundaries and broken/changed consent membership still reject them.
Legacy null keeps the exact next-global-manifest cutoff. All existing checks on
run, immutable policy/consent, lane, count-domain carrier, retained epoch, deletion,
completeness and source counter timeline remain in place. No new API or state.

This selection does not carry a live counter, change operation-lease authority,
activate a provider/writer, or modify portable file semantics. Those remain open.
Only the existing read-only native selector is changed. Shared working drafts
are untouched. Independent source review is accepted; no gate has run.

prepares validated primitive interval bounds once per run in O(M log M); the
selector uses O(1) bound lookups per fact. The existing single-interval method
uses the same helper. No service, observer, store, wire or acquisition rule is
added. Two helper contract methods cover legacy/missing membership/real restart,
equal-time boundaries, invalid consent, negative/reversed intervals and unbounded
last recording. V1 source and metadata remain in REVIEW_V1. V2 independently accepted; see SOURCE_REVIEW.md.

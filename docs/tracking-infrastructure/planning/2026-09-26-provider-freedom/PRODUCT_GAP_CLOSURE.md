Applied request success alone is insufficient. If high detail is unavailable but baseline works, use **“Recording · detail limited”** plus the relevant reason/action; never turn a working source off solely because level 4 cannot be reached.

Background collection continues.”** only when that collection is actually enabled. Stop remains available in every such state and is idempotent.

## 5. Organization and historical actions

### 5.1 Create and edit

Add **Add session** to the existing history action area. Form fields: optional name, start/end date and time, existing optional session label, displayed time zone. One live group can be open; overlaps between closed/retrospective groups are allowed. A local group contains current qualified retained facts in its interval, not copies or reattributed records. Imported groups are restricted to their explicitly bundled source-entry/day bindings and qualified corrections; unrelated data at the same time is excluded. Active group Edit permits name and existing label only; **End session to edit its time** is the concrete alternative. Removing an active group is unavailable until End; data erase during acquisition follows the source owner's existing safe boundary and must not be approximated through a group delete.

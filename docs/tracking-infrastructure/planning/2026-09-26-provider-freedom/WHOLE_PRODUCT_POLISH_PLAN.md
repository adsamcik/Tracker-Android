A missing route must not become “no data”; an unknown value must not become zero; compact copy must not hide uncertainty or change file provenance. Changes below repair concrete joins and explanations around existing functionality. Static review cannot establish visual polish, platform behavior or universal completeness.

## 4. Element and copy contract

Every changed element must identify five fields: the user's task/decision, qualified source of truth, action if needed, when it is shown, and why its prominence is justified. Remove duplication, not evidence. Ordinary rows show source, period, value/state and origin only where useful; Details/files retain exact purpose, uncertainty, coverage, units and provenance. Opaque IDs, writer numbers and containment codes belong in technical Details. A contained source must not offer an ineffective permission repair. Primary actions remain prominent; contextual limitations appear beside the affected value/action only when applicable.

| Element | Proposed concise result | Essential truth/action |
| --- | --- | --- |
| Start area | “Ready to record” / “Steps and Wi-Fi available · Cell needs access” | One Start; Review Cell only for an actual repair. No duplicate hero/empty/help paragraphs. |
| Active area | Elapsed time plus actual selected source states and Stop | No speed/path slot without qualified Location. Last saved time is not observation freshness. |

| Terrain | “Height shows relative density of recorded locations” | Fewer/More observations; sampling caveat in layer Details. Correct/omit old 10m copy against actual25m; no dwell claim. |

Proposed row wrapping and density are source-derived risks to check later, not observed rendering defects. No new permanent badges or warnings for every low-level proof field.
